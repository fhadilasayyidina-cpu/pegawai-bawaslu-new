# Images Directory

Tempatkan file logo Bawaslu Sulsel di sini.

## Nama file yang dibutuhkan:
- `bawaslu-sulsel-logo.png` - Logo utama aplikasi

## Cara mengubah logo:
1. Letakkan file logo di direktori ini dengan nama `bawaslu-sulsel-logo.png`
2. Atau ubah path di file `.env`: `APP_LOGO=/path/to/logo.png`
3. Atau ubah langsung di `config/app_custom.php`

## Pengaturan di satu tempat:
File `config/app_custom.php` adalah sumber utama untuk:
- Nama aplikasi (`name`)
- Logo aplikasi (`logo`)
- Nama organisasi (`organization.short_name` dan `organization.full_name`)
